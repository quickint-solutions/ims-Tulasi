Printing notes

Browser printWorks with any OS-installed printer, including the Seznik Mini and other thermal units. Set the paper size to 50 × 25 mm and margins to none in the print dialog.
USB / Bluetooth thermalInstall the vendor driver so the unit appears as a normal OS printer, then select it in the browser print dialog.
Network printerRecord host:port here for reference; printing still goes through the OS queue.
ESC/POSTick supports ESC/POS to record the capability. The label layout itself is HTML/CSS at true millimetre size, so no printer-specific language is required.
CalibrationUse Test print and measure the result. If it is off, adjust label gap and margin on the profile rather than the layout.
