How to call the API

curl -H "Authorization: ApiKey <your-key>" \
     {{ request.scheme }}://{{ request.get_host }}/api/v1/items/

curl -X POST -H "Authorization: ApiKey <your-key>" \
     -H "Content-Type: application/json" \
     -d '{"document_number":"IN-001","warehouse":"MAIN","lines":[{"item":"SP-001","location":"MAIN/RACK-A/C-01/T-03","quantity":10}]}' \
     {{ request.scheme }}://{{ request.get_host }}/api/v1/stock/inward/

Every endpoint is quantity-only. Writes need a key with the write scope and a user whose role carries the matching permission.
